# Rewards Page Background Music

Place your audio file here as `rewards-bgm.mp3`.

Recommended:
- Format: MP3
- Duration: 2-5 minutes (will loop)
- Volume: keep peaks below -6dB so it stays subtle
- License: ensure you have rights to use the track

If you want a royalty-free alternative, try:
- YouTube Audio Library
- Free Music Archive
- Epidemic Sound
